# Orijental moja cvećara — Next.js

Moderni rebrending sajta [cvecaraorijental.com](https://www.cvecaraorijental.com/) u Next.js-u, sa glassmorphism dizajnom i animacijama.

## Pokretanje

```bash
cd ~/Developer/cvecara-orijental
npm install
npm run dev
```

Otvori [http://localhost:3000](http://localhost:3000).

## Stranice

- `/` — Početna
- `/buketi` — Buketi i aranžmani
- `/saksisko-cvece` — Saksijsko cveće
- `/rezano-cvece` — Rezano cveće
- `/program-za-saucesce` — Program za saučešće
- `/o-nama` — O nama
- `/kontakt` — Kontakt

Logo, fotografije i hero video se učitavaju sa postojećeg Webflow CDN-a.
